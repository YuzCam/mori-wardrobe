# 手机验收

重点设备：华为 Mate 80 Pro，HarmonyOS 6，华为浏览器。

## 已实现的适配

- viewport-fit=cover、底部 safe-area、动态视口高度回退。
- 360px 起的手机布局，双列衣物卡片、底部导航与可滚动筛选。
- 相册与拍照分别使用文件选择器；拍照声明 environment capture，具体入口由浏览器决定。
- 工作图片最长边缩至 1400px，模型分别使用 320px 和 224px 输入，顺序执行。
- Canvas Pointer Events 与坐标缩放；画笔/圈选禁用区域内默认触控滚动，其他位置仍可滚动。
- 单线程 WASM，不要求 WebGPU 或 SharedArrayBuffer。
- 草稿随操作保存；识别可取消，失败可手动完成，图片保留。
- 城市搜索与手动天气作为定位权限不可用时的入口。

## 必须在实际手机验证

已在桌面浏览器的同源预览框架检查 360px 衣橱、390px 首页、430px 上传布局；未看到横向溢出。完整浏览器流程已验证合成衣物图片的实际抠图与分类、手动确认、持久化、详情读取、修改背景后保留标签与同 ID 更新。合成插画不等于真实衣物准确率基准，也不等于 Mate 真机通过。

1. 相册与拍照回传、照片方向和 8192×6144 大图。
2. 画笔、圈选、裁剪、缩放，以及长页面滚动。
3. 键盘弹出、地址栏伸缩、横竖屏与底部按钮。
4. 首次模型下载、后续缓存读取、实际推理耗时与内存。
5. 切到后台再返回、关闭页面后恢复草稿。
6. 私有站点登录 Cookie、天气网络可达性与拒绝定位。
7. 系统是否提供添加到主屏幕；此能力由实际浏览器决定。

CSS 视口测试与桌面浏览器执行不能替代上述真机验收。
