# Yu's Mori · 鸿蒙离线衣橱

这是面向华为 Mate 80 Pro 的鸿蒙应用工程。界面、识别模型及图片处理运行资源均内置，不需要打开 chatgpt.site，不需要 ChatGPT 登录。

## 0.2.1 更新

- 回收站单品详情新增“永久删除”，二次确认后在同一事务中清除衣物记录、4类图片和对应编辑草稿。仅回收站衣物可永久删除；确认后记录或关联变化会中止操作，写入失败整批回滚。
- 关联搭配（包括已收起搭配）及相关搭配草稿会先列出，只有额外勾选确认才会一起永久删除；搭配中其他衣物保留。可取消后先去搭配区调整关联。
- 设置新增“本机图片占用”，统计图片Blob大小，含回收站、图片草稿和搭配预览；不等于系统统计的应用总占用，不包含安装包、内置模型、数据库额外空间或已导出的备份。
- 照片位于应用私有空间中的 IndexedDB，不是相册文件夹，也不会上传云端。占用手机存储容量，查看或编辑时才需要载入内存；永久删除后由数据库及系统回收或复用空间，系统显示的占用可能不会立即减少。相册原照片和既有ZIP备份不受影响。
- 50项自动化测试与两套类型检查通过，新增覆盖删除范围、关联确认、过期确认保护、草稿、删除失败回滚、删除后备份及空间统计。验证记录以 `outputs/harmonyos-build.json` 为准。

## 如何完成手机安装

1. 此电脑已经安装 DevEco Studio，目录为 `D:\Huawei\DevEco Studio`，SDK、Node和Java均已可用于编译。更换电脑时请安装华为官方工具并完成SDK配置；相关协议由账号持有人确认。
2. 在 DevEco Studio 中打开本 README 所在的 `harmonyos` 工程目录。打包交付的工程已包含全部离线资源，不用重新安装网页开发依赖。
3. 将 Mate 80 Pro 连接电脑，在手机上由本人启用调试并确认授权。
4. 在工程的 Signing Configs 中由本人登录华为开发者账号，为自己的手机生成调试签名。签名配置必须绑定到 `default` product。证书、私钥、密码和设备配置只保留在本机，不要发送到聊天或提交到代码仓库。当前 `build-profile.json5` 为忽略的本机文件；新检出可从 `build-profile.template.json5` 复制后重新签名。工程归档脚本会清空签名材料和签名引用，不改变本机工作配置。
5. 使用 Run 安装到手机，逐项进行下方验收。首次运行应没有任何示例衣物；电脑本地预览的数据与手机数据独立。

调试签名可能需要按华为规则更新；若要长期免调试使用，应采用符合华为要求的正式分发或测试分发流程。

## 本版功能

- 相册选择或系统相机拍照；单张图片上限20MB。
- 本机 U2NetP 抠图、CLIP 分类和色系提取。识别可取消，失败后保留图片供手动整理。
- 裁剪、圈选主体、擦除、恢复细节、亮度、对比度、旋转及纯色背景。
- 品类、春秋/夏/冬季节、色系、风格、名称和备注；自动结果均可修改。
- 网格衣橱、搜索、多组筛选与排序，图片按需读取。
- 自动草稿、可恢复的回收站、逐件永久删除、图片空间统计、完整备份与恢复。
- 没有天气、穿搭推荐、手机电脑同步、云端登录或衣物上传。

## 数据与备份

衣物元数据与原图、处理图、缩略图、蒙版使用 IndexedDB 原子事务保存。存储绑定应用内部固定来源 `https://mori-app.invalid`；这是保留的本地域名，由应用拦截并从安装包读取，不是互联网服务器。更换该来源、包名或清除 Web 数据会影响已有存储，后续更新必须保持不变。

卸载应用、清除应用数据，或系统清理应用内部存储可能导致数据丢失。请定期把备份导出到系统“文件”中。禁止在升级流程中调用清理 Web 数据接口。

备份以ZIP输出，包含原图、单品图、缩略图、蒙版、标签和回收站。超过48MB自动分卷，所有分卷一起才是完整备份。恢复前检查体积、版本、标签和每个图片的SHA-256；每卷在一个数据库事务内导入，失败全部回滚。同一卷重复恢复不会重复添加，当前较新的编辑不会被覆盖；编号碰撞时保留原有衣物并为备份副本重新编号。支持原网页版的沐衣ZIP备份，忽略其中的天气、搭配等数据。

## 鸿蒙真机验收清单

- 启动、强制关闭后重开、重启手机后，照片和标签均仍在。
- 相册导入、取消选择、拍照、取消拍照均能正常返回。
- 飞行模式下重新打开应用，仍能导入已在本机的照片、手动整理、保存、搜索、筛选和恢复回收站衣物。
- 飞行模式下内置模型能够读取并运行；记录抠图、分类耗时及内存，取消后不占用后台资源。如果 ArkWeb 对 Worker、WebAssembly 或本地来源存在限制，需要继续适配，不得当作已经通过。
- 第一次启动时确认 IndexedDB 可持久保存、二进制本地资源拦截能返回正确 MIME；工程不声明网络权限，必须确认当前 ArkWeb 能正常读取这些被拦截的本地 HTTPS 资源。
- 系统文件保存器能导出完整ZIP；用另一份本机数据库导入，确认图片和标签一致，回收站状态保留。
- 系统返回键先关闭详情/筛选，再返回衣橱；衣橱页面再次返回退出应用。
- 使用系统“大字体”、手势导航、横竖屏切换检查遮挡、点击区域和底部避让。
- 覆盖安装更新后原有衣橱仍在；不进行卸载重装式升级。

## 后续开发

上一级项目的 `offline/src` 是界面、数据和备份源代码，`workers/image-processing.worker.ts` 是本机识别模块。修改后在上一级运行：

```text
node scripts/build-offline.mjs
```

该命令会构建界面、校验内置模型SHA-256，并更新 `entry/src/main/resources/rawfile/offline`；不会生成、签名或安装HAP。
